Так как исходные CSV-файлы не были предоставлены, был разработан скрипт генерации тестового датасета.

Для генерации тестовых данных использовалась библиотека Faker. В логику генерации были заложены вероятности появления 
описанных в ТЗ аномалий: повторные event_id с обновленной выручкой, задержки ingested_at относительно event_time на 
срок до нескольких дней, невалидные значения country ('--', пустые строки, нижний регистр), тестовый 
трафик (is_test = true), а также разделители в виде запятых и "NULL" в финансовых полях. Для ускорения работы при создании
скрипта использовался ИИ-инструмент Antigravity.

Надо учитывать возможность наличия некорректных данных в исходных файлах. 
Поэтому таблица events_raw рассматривается как промежуточный слой, и все столбцы из CSV-файлов загружаются как текстовые. 
Это позволит сохранить исходные значения и проверить/преобразовать их типы позже. 
По условиям задачи в денежных типах данных разделитель запятая, а не точка.
В остальных таблицах по условиям задания нет некорректных данных, поэтому не будем усложнять.

Строка считается невалидной для конкретной задачи, если отсутствует или некорректно значение поля, необходимого для выполнения этой задачи. 
В рамках задания реализуется обработка только тех некорректных случаев, которые явно указаны в задании. 
Для остальных случаев предполагается, что исходные значения корректны по умолчанию.

Поля revenue_usd и country обрабатываются по специальным правилам задания и сами по себе не являются причиной отправки строки в карантин.

Задача 2.1 — Удаление дубликатов 

Если несколько записей имеют одинаковые event_id и ingested_at (что на практике маловероятно), выбор строки произойдет 
случайным образом. Необходимы дополнительные правила для выбора актуальной записи, которых нет в условиях задачи.

Для полей event_time и ingested_at предполагаем, что они содержат корректные значения даты и времени в текстовом формате.
Для поля is_test предполагаем, что оно содержит корректное значения false в текстовом формате, остальные значения по умолчанию true.
